HOW TO PLAY

三步开战

下载并运行启动器

按平台下载启动器，解压运行，填入游戏实例目录（默认 .minecraft）。

注册 / 登录账号

在启动器内用邮箱验证码注册（或先在网页注册），然后登录。也可在 auth.geekhonize.top 注册。

打开游戏 = 你的账号

启动器把登录写进客户端配置；进入服务器后自动完成账号绑定，角色与进度随账号走。

服务器地址：play.geekhonize.top:25565（游戏内主菜单一键直连）

ACCOUNT

一个账号通行全部作品（BREAKFRONT / 账号中心 / 后续内容）。在此注册或登录后， 启动器与网页登录互通；忘记密码可在账号中心用邮箱验证码找回。

登录后会发生什么

启动器登录 → 会话写入实例配置 → 客户端进服自动绑定。游戏内聊天显示 [Geekhonize] 绑定：用户名（player / admin…），管理身份由该账号角色决定。

FAQ

常见问题

  • 为什么必须有账号？

    离线服无法靠正版 ID 识别身份，账号用于绑定身份与防冒名，也是战绩与角色的载体。

  • 注册要邮箱吗？

    要。注册时通过邮箱验证码验证归属，并可用它找回密码或换绑邮箱。

  • 启动器登录后游戏里就是该账号吗？

    是的。登录会话写入客户端配置，进服自动与服务器绑定，游戏内显示你登录的 Geekhonize 用户名。

  • Android 支持吗？

    启动器已按 Win / Linux / Android 一套代码开发，桌面版先发，Android APK 随官网开放。

  • 进不去服 / 卡连接怎么办？

    确认已从官网更新客户端；仍失败可在游戏内或官网提交问题描述给管理员。
