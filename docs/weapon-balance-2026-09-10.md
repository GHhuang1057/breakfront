# BREAKFRONT 战斗数值：TTK/BTK 重标（2026-09-10）

## 一、问题与依据

原 `WeaponCatalog` 数值全面偏弱，实测近距 TTK 是 BF2042 基准的 **1.5–3 倍**，
且狙击枪无法一枪致死 —— 这也是「战斗系统约等于没做」的直接体现。

重标依据（网上调研，TTK 不含反应时间）：

- **BF2042 TTK 档位**（Game8 BTK/TTK 实测表 + Sym 数据挖掘）
  | 档位 | TTK 区间 | 代表 |
  |---|---|---|
  | 顶级 | 200–223 ms | AC9 SMG（CQC 223–241ms） |
  | 优秀 | 240–270 ms | VHX-D3 AR 267ms |
  | 中档 | 267–300 ms | 多数 AR |
  | 偏低 | 356–401 ms | 长弹匣/远距惩罚态 |
- **通用公式**：`TTK = (60 / RPM) × (BTK − 1)`
- **BF2042 各族典型 BTK**：AR 近距 4–5 发（单发 22→15）、SMG 近距 5–6 发、
  DMR 2–3 发、SR 1–2 发、霰弹近距 1–2 壳

## 四、设计意图

- **AR**：全能。近距 4 发、30m 5 发、60m 6 发 —— 衰减平滑，任何距离都可用。
- **SMG**：近距霸主。高射速（950rpm）低单伤，12m 内满伤、36m 后跌至一半，
  逼出「贴脸打」的战术身份。
- **LMG**：持续火力。单发 22、最低比 0.68（**远距衰减小**，60m 仍 6 发），
  换取较大的持枪/开镜迟滞（后续在武器手感层实现）。
- **DMR**：2 发击杀（50×2=100），30m 内满伤，远距 3 发 —— 中远距压制位。
- **SR**：**躯干一枪致死**（105 > 100HP），200m 处衰减到 89 伤需 2 枪。
  这是狙击手身份的硬要求，原表 76 伤做不到。
- **霰弹**：按「壳」计（整发总伤）。全自动 aa12 靠射速、致死距离短（12m）；
  泵动 m590 靠单发威力、致死距离远（18m）—— 两者是明确的取舍关系。
- **手枪**：副武器应有明显劣势，近距 5 发、有爆头回报（1.7×）。

## 五、回归保障

`core/src/test/java/com/breakfront/weapon/WeaponBalanceTest.java`（28 断言）把
上述基准写成断言，覆盖：各族 BTK/TTK 上限、SR 躯干致死、霰弹致死距离取舍、
爆头必为正收益、族间 TTK 单调性。

本地快速验证（无需 Gradle）：

```bash
bash scripts/run_core_tests.sh          # 跑武器平衡 + 管理台解析测试
bash scripts/run_core_tests.sh --ttk    # 打印本文档的对照报告
```
