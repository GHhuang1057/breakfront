# BREAKFRONT 物品栏系统重做 · 设计草案 v1（2026-09-09）

## 背景
原版背包（36 格自由存取 + 丢弃 + 捡拾）与战地攻防玩法冲突：
- 兵种装（Kits）会被玩家挪用/囤积，破坏 32v32 平衡；
- 掉落物满地（枪/弹药/方块）污染战场与性能；
- 死亡清算语义（BF 系死亡即失去全部装具）无法表达。

## 目标形态（BF2042 语义）
服务端权威的「兵种装槽位制」，玩家无自由背包：

| 槽位 | 内容 | 来源 |
|---|---|---|
| 主武器 | 兵种 TaCZ 枪（不可卸下） | Kits |
| 副武器 | 手枪（批 C 后续） | Kits |
| 战术装备 | 兵种手雷/补给（按兵种） | Kits |
| 近战 | 小刀（固定） | 通用 |
| 弹药 | 主武器备弹（数字显示，不占格） | Kits |

- 拾取：仅允许拾取「同兵种武器补充弹药」（TaCZ 弹药实体），其余落物直接销毁。
- 丢弃：全禁（已由服务端 1s 掉落物清扫兜底 + 后续取消 Q 包）。
- 死亡：装具全失，复活按兵种重发（现有 AFTER_RESPAWN 链路已满足）。
- 切换兵种：/bf kit <class>（已有，权限 2）；正式版走部署界面选择。

## 分期
1. **本期（服务端地基）**：掉落物清扫（已上线）、复活重发装、/bf kit 自助、领地判定可视化。
2. **下一批（锁定层）**：拦截 InventorySlot/CreativeSlot C2S 包与 Q 丢弃包（ServerPlayInventory mixin），
   把玩家背包做成只读「兵种条」。
3. **再下一批（客户端 UI）**：矢量 HUD 兵种槽位条（BfDraw 绘制），替换原版 hotbar 渲染；
   部署界面兵种/装具选择树。
4. **远期**：弹药数字模型、战术装备冷却、人机同规则。

## 风险
- TaCZ 枪有内部耐久/弹药 NBT，锁定背包后换弹依赖 TaCZ 自身逻辑（可行，它只操作主手）。
- PCL/FCL 玩家与自研启动器行为一致（全部服务端权威，无客户端依赖）。
