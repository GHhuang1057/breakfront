### 3. 游戏内地图扇区编辑器（手动圈据点/扇区 → 落盘 → 热应用）
- 数据：`core .../map/SectorLayout.java` —— 有序扇区 → 据点{x,z,radius} 的唯一事实来源，
  JSON 持久化（Gson），内置 viaduct 兜底布局。
- 服务端 `/bfs`（权限2）：
  - `on/off` 开合编辑器（仅自己可见地面圆环预览）
  - `here [半径]` 在准星所指方块加据点（默认 r=8）；`move/resize/remove/undo`
  - `sector next|prev|list|name` 当前扇区游标（next 到底自动建新扇区；名称可改）
  - `list/status/help/clear`
  - `save/load/apply`：落盘 `breakfront/sectors.json`、从盘装载、**应用=保存+重建对局回大厅**
- 服务端启动时自动装载 `runDir/breakfront/sectors.json`（缺失回退 viaduct），
  地图坐标从此**跨重启持久**，取代旧 `ServerMatch` 硬编码/临时 /bf anchor。
- 协议：新增 S2C `SectorEditPayload`（core 注册 + client 编译桩，client jar 仍排除 net/**）。
- 客户端：`SectorEditState` + `SectorPreviewRenderer`（世界空间地面圆环，按扇区分色、
  当前扇区加粗 + 中心菱形光标），渲染路径同 WorldZoneRings（兼容 Sodium/VulkanMod）。

## 用法示例（游戏中 op）
```
/bfs on
（走到地铁地图某段）准星对准地面 /bfs here 10     # 当前扇区加据点 A1
（走远一点）            /bfs here 10             # 加 A2
/bfs sector next                                  # 新扇区「扇区二」
/bfs sector name 中段                              # 可选重命名
（继续圈 B1/B2…）
/bfs list
/bfs save
/bfs apply                                        # 应用并回大厅，AI 填充自动重开
```

## 修订（2026-09-05 追加）：客户端渲染方案弃用 VulkanMod
- 实测 VulkanMod 0.6.7 × TaCZ:Refabricated **启动即崩**：TaCZ 客户端初始化对内部 FBO 开模板缓冲（stencil，格式 36013），VulkanMod `GlUtil.vulkanFormat` 不识别 → `IllegalStateException`。
- 处理：客户端实例 mods 移除 VulkanMod；Iris 1.8.8 + Sodium 0.8.13 就位为唯一渲染器，配 ComplementaryReimagined r5.9 光影；删除 renderer/ 双配置目录与 BF_render_switch.bat，BF_renders_README.md 改写为单一方案说明。
- charter §2.3 已同步定案（VulkanMod 弃用，Sodium+Iris 为主方案）。
